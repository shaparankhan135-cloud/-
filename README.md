# SNAPFIX Real MVP v0.2.0

This build is a real local/offline MVP, not just a UI demo.

Working:
- Gallery photo picker
- Real image preview
- Real basic enhancement (local bitmap processing)
- Real JPEG compression
- Save compressed/result image to Pictures/SNAPFIX
- Real single-image PDF creation to Documents/SNAPFIX
- Share result
- Local demo credit counter

Not yet included:
- Cloud AI
- ML Kit OCR (next module)
- True AI background removal
- AdMob
- Premium billing
- Backend/auth/database

Build:
1. Open the project in Android Studio.
2. Sync Gradle.
3. Run on an Android 8+ device/emulator.
4. Choose a photo and test Enhance, Compress, Image→PDF, Save and Share.

No paid API key is required for this build.
